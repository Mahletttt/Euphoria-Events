# Euphoria Events

### Where Every Moment Becomes a Celebration.

## About the Project

Euphoria Events is an event discovery and registration website designed to help visitors explore different types of events and find exciting experiences.

The website provides information about events, allows visitors to explore event categories, and offers a registration form for those interested in participating.

## Project Objectives

- Make discovering events easier.
- Present different event categories.
- Provide information about upcoming events.
- Allow visitors to express their interest through a registration form.

## Website Pages

1. **Home (`index.html`)** – Introduces Euphoria Events and highlights featured events.
2. **Events (`events.html`)** – Displays event categories and event information.
3. **Register (`register.html`)** – Provides a form for visitors interested in registering for events.
